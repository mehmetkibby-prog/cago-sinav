# V26.31 Güncellemesini Mevcut GitHub Deposuna Yükleme

Bu paket mevcut V26.30 deponuzu V26.31'e yükseltir. AGS tablet ekranındaki
kart başlığı çakışmasını ve kesilen konu filtrelerini düzeltir; diğer özellikleri
değiştirmez. Ayrıca bu sürümden itibaren APK'lar aynı kalıcı anahtarla imzalanır.

1. `V26.31-GitHub-Guncelleme` klasörünün içindeki bütün klasör ve dosyaları
   GitHub deposunun ana dizinine yükleyin.
2. GitHub aynı adlı dosyalar için değişiklik gösterecektir; yüklemeyi onaylayın.
3. `.github/workflows/main.yml` dosyasının da yüklendiğini kontrol edin.
4. Ayrı verilen **GitHub Sabit İmza Kurulumu** paketindeki iki değeri GitHub
   **Settings → Secrets and variables → Actions** alanına ekleyin:
   `ANDROID_KEYSTORE_BASE64` ve `ANDROID_KEYSTORE_PASSWORD`.
5. **Actions → APK oluştur → Run workflow** seçeneğini çalıştırın.
6. İşlem yeşil tik olunca
   **Muzik-Sinavi-Android-V26.31-Guncelleme-APK** çıktısını indirin.
7. ZIP'in içindeki `Muzik-Sinavi-Android-V26.31-Guncelleme.apk` dosyasını
   tablete kurun.

V26.30'un geçici imzası geri alınamadığı için V26.31 kurulurken son kez eski
uygulamayı kaldırmak gerekir. V26.31'den sonraki sürümlerde aynı APK'nın üzerine
kurulum yapılır ve yerel veriler korunur. Sabit imza paketini GitHub'a yüklemeyin.

Mac'te `.github` klasörü görünmüyorsa Finder'da `Command + Shift + .` tuşlarına
basın. Depoya bu teslim ZIP'ini tek dosya olarak yüklemeyin; önce ZIP'i açın.
