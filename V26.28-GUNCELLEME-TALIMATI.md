# V26.28 Güncellemesini Mevcut GitHub Deposuna Yükleme

Bu paket V26.27 dosyalarının bulunduğu mevcut depoyu V26.28'e yükseltir.

1. `V26.28-GitHub-Guncelleme` klasörünün içindeki bütün klasör ve dosyaları
   GitHub deposunun ana dizinine yükleyin.
2. GitHub aynı adlı dosyalar için değişiklik gösterecektir; yüklemeyi onaylayın.
3. `.github/workflows/main.yml` dosyasının da yüklendiğini kontrol edin.
4. **Actions → APK oluştur → Run workflow** seçeneğini çalıştırın.
5. İşlem yeşil tik olunca
   **Muzik-Sinavi-Android-V26.28-Tablet-Duzeltmeli-APK** çıktısını indirin.
6. ZIP'in içindeki `app-debug.apk` dosyasını tablete kurun.

Mac'te `.github` klasörü görünmüyorsa Finder'da `Command + Shift + .` tuşlarına
basın. Depoya bu teslim ZIP'ini tek dosya olarak yüklemeyin; önce ZIP'i açın.
