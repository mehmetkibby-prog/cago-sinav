# V26.29 Android Güncellemesi

1. Bu klasörün içindekileri mevcut GitHub deponuzun ana dizinine yükleyin.
2. GitHub sorarsa aynı adlı dosyaların üzerine yazılmasını onaylayın.
3. `.github`, `native-android`, `tests` ve `www` klasörlerinin yüklendiğini kontrol edin.
4. Actions > APK oluştur > Run workflow yolunu izleyin. Eski başarısız işi yeniden çalıştırmayın.
5. İşlem yeşil tik olduğunda `Muzik-Sinavi-Android-V26.29-Kalici-Tablet-Duzeltmeleri-APK` çıktısını indirin.

Bu sürüm yalnız Android/tablet içindir. API anahtarı alanındaki klavye odağı,
tüm öğretici metinlerde cümle seçme/kaydetme ve AGS tablet yerleşimi düzeltilmiştir.
